# SUUMO 土地検索 URLパラメータリファレンス

## ベースURL

```
https://suumo.jp/jj/bukken/ichiran/JJ012FC001/
```

## 必須パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| `ar` | `030` | エリア（030=関東） |
| `bs` | `030` | 物件種別（030=土地） |

## エリア指定

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| `ra` | 地域コード | `030013` = 東京都（城南エリア） |
| `rnek` | 駅コード | `000539110` = 目黒駅 |
| `rn` | 沿線コード | `0005` = JR山手線 |

## 価格条件

| パラメータ | 説明 | 値の例 |
|-----------|------|--------|
| `kb` | 価格下限（千万円単位のインデックス） | `1`=下限なし |
| `kj` | 価格上限 | `9`=上限なし |
| `kt` | 坪単価上限 | `9999999`=上限なし |

### 価格インデックス対応表（kb/kj）

| 値 | 価格 |
|----|------|
| 1 | 下限/上限なし |
| 2 | 500万円 |
| 3 | 1000万円 |
| 4 | 1500万円 |
| 5 | 2000万円 |
| 6 | 3000万円 |
| 7 | 4000万円 |
| 8 | 5000万円 |
| 9 | 上限なし |

## 面積条件

| パラメータ | 説明 | 値の例 |
|-----------|------|--------|
| `mb` | 面積下限（m²） | `0`=下限なし |
| `mt` | 面積上限（m²） | `9999999`=上限なし |
| `km` | 坪単価下限 | `1`=下限なし |

## 駅徒歩

| パラメータ | 説明 | 値の例 |
|-----------|------|--------|
| `et` | 駅徒歩上限（分） | `9999999`=指定なし, `5`, `10`, `15`, `20` |

## 表示設定

| パラメータ | 説明 | 値の例 |
|-----------|------|--------|
| `pc` | 1ページ表示件数 | `30`, `50` |
| `pj` | ページ番号（1始まり） | `1`, `2`, `3` |
| `po` | ソート順 | `0`=おすすめ順 |
| `cn` | ? | `9999999` |
| `hb` | ? | `0` |
| `ht` | ? | `9999999` |
| `ni` | ? | `9999999` |
| `ohf` | ? | `0` |
| `tb` | 建ぺい率下限 | `0` |
| `tj` | 建ぺい率上限 | `0` |
| `tt` | 容積率上限 | `9999999` |

## URL構築例

### 目黒駅周辺の土地（全件、30件/ページ）

```
https://suumo.jp/jj/bukken/ichiran/JJ012FC001/?ar=030&bs=030&ra=030013&rnek=000539110&rn=0005&cn=9999999&et=9999999&hb=0&ht=9999999&kb=1&kj=9&km=1&kt=9999999&mb=0&mt=9999999&ni=9999999&ohf=0&pc=30&pj=1&po=0&tb=0&tj=0&tt=9999999
```

### ページ2へ移動

`pj=2` に変更するだけ:

```
...&pc=30&pj=2&po=0...
```

## 主要駅コード（rnek）

SUUMOの駅コードはサイトで検索して確認する必要がある。以下は参考値:

| 駅名 | rnek | rn（沿線） |
|------|------|-----------|
| 目黒 | `000539110` | `0005`（JR山手線） |

## 注意事項

- ページネーションは `pj` パラメータで制御される
- 1ページ最大30件（`pc=30`）
- 検索結果が0件の場合、`.property_unit` 要素が存在しない
- URLのエンコードには注意（特に `&` の扱い）
